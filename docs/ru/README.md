# Machine Loader - Русский

Загрузчик модов для игры Aviassembly (аналог Forge/Fabric для Minecraft)

## Возможности

- **Управление модами** - управление модами через кнопку Mod в главном меню
- **Папка mods** - автоматическое создание папки mods в каталоге игры
- **16 встроенных модов** - боевая система, радар, ракеты, голосовые оповещения и др.
- **Автообновление** - система автообновления с проверкой подписи SHA-256 + RSA-3072
- **Мультиплеер** - поддержка онлайн/LAN комнат
- **Многоязычность** - документация на 7 языках

## Установка

1. Скачайте `MachineLoader-2.5.0.zip` со страницы [Releases](https://github.com/AODOJUST/MachineLoader/releases)
2. Распакуйте и запустите `MachineInstaller.exe`
3. Установщик автоматически обнаружит Aviassembly
4. Подтвердите путь установки и установите
5. Запустите игру - если в левом нижнем углу главного меню отображается `Machine v2.5.0`, установка прошла успешно

## Быстрый старт

### Установка модов
1. Поместите DLL-файл мода в папку `каталог игры/mods/`
2. Перезапустите игру
3. Включите/выключите мод через кнопку Mod в главном меню

### Разработка собственных модов
См. [Руководство по разработке модов (английский)](../en/mod-development.md).

## Список встроенных модов

| Мод | Описание |
|-----|----------|
| BattleCore | Боевой информационный хаб (зависимость) |
| BattleHold | Управление боевым складом |
| CombatBay | Боевая грузовая палуба |
| FactionSystem | Система ИИ для 3 фракций |
| FlightTrails | Отображение следов полёта |
| GMeter | Расчёт перегрузки G |
| GVision | Боевой индикатор на лобовом стекле |
| KillFeed | Лента событий убийств |
| MachineAAM | Ракеты «воздух-воздух» + пушка |
| MachineShop | Независимый интерфейс грузового магазина |
| OptiMod | Оптимизация производительности CPU |
| Radar | Многоуровневый радар + захват цели |
| VoiceAlerts | Китайско-английские голосовые оповещения |
| ZoomMod | Масштабирование экрана |
